# Munkaszabályok (value-scanner)

- A felhasználó Tibi (Varga Tibor). Vele mindig **magyarul** kommunikálj.
- A projekt teljes leírása és a teendők: **`docs/PROJEKT.md`**. Munka előtt olvasd el.
- Szerkesztés előtt mindig `git fetch origin main && git rebase origin/main`, mert több munkamenet pushol.
- Push előtt `npm test`, mindennek zöldnek kell lennie. Új funkcióhoz írj tesztet (`test/`).
- A Render a `main` ágról automatikusan deployol: amit pusholsz, az élesbe megy.
- Tilos: `.env`, kulcs vagy session a repóban; Sportfolio-tartalom nyilvános csatornában; szkennelő GitHub workflow.
- Nyilvános posztban nem lehet irodanév; a szöveg magyar, tizedesvesszővel.
